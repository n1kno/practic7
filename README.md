# practic7

TCP чат (TCP сервер и TCP клиентом) 1 к 1-ому пользователю
Схема такая:

Пользователь 1 запускает программу-клиент и вводит свой УНИКАЛЬНЫЙ ник, после чего подключается к серверу и отправляет этот ник(если ник не уникальный, то сервер должен сообщить об этой ошибке)
Пользователь 2 запускает программу-клиент и вводит свой ник
Пользователь 2 вводит ник пользователя 1 и сообщение для пользователя 1, после чего отправляет сообщение и это сообщение отображается в терминале ТОЛЬКО у пользователя 1
Если ника пользователя нет в системе, то должно отображаться сообщение об ошибке в терминале
